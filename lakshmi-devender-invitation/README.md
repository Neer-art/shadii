# Lakshmi & Devender — Wedding Invitation

A responsive, static wedding invitation website built with HTML, CSS and vanilla JavaScript. No build step is required.

## Run locally
Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder (keep `index.html` at the repository root).
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Choose **Other** as the framework preset. Leave Build Command and Output Directory empty.
5. Click **Deploy**. Vercel will provide a public URL you can share on WhatsApp.

You can also use Vercel's CLI from this folder: `npx vercel`.
