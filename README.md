# Lakshmi & Devender — Royal Wedding Invitation

A responsive static wedding invitation website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive royal maroon, cream and gold design
- `script.js` — live countdown, mobile navigation and back-to-top button

## Preview locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload the contents of this folder directly to the root of your GitHub repository. Do not upload the ZIP itself or an extra nested folder.
3. Commit the files to the `main` branch.
4. Open your Vercel `wedding` project → Deployments. The new GitHub commit should trigger a deployment.
5. If it does not, open Project Settings → Git and verify the connected repository is `Neer-art/wedding` and Production Branch is `main`, then redeploy the latest commit.

For this static site use Framework Preset `Other`; leave Build Command, Install Command and Output Directory empty.
